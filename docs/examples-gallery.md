# Examples Gallery

> **Where**: `examples/gallery/` — open from PulsimGui via **File →
> Open** and just press **Run** on the Run Bar.

Fifteen canonical power-electronics topologies, ready to simulate.
Each example is a complete `.pulsim` project (schematic + simulation
settings + scope window) and matches the corresponding test circuit
used by the Pulsim runtime benchmarks. Use these as starting points,
templates, or reference designs.

All circuits were generated by `scripts/generate_examples.py`. To
regenerate or modify the gallery in bulk, edit that script and re-run
from the repo root.

## DC-DC step-down

### Buck (open loop)

**File:** `examples/gallery/buck_open_loop.pulsim`
**Topology:** classic single-switch buck, 12 V → 5 V nominal at 100
kHz, 42 % duty. Diode catches the inductor freewheel current.
**Components:** `Vin` (DC), `M1` (NMOS), `D1`, `L1` (220 µH), `Cout`
(47 µF), `Rload` (5 Ω), `PWM1` driving the gate.
**Simulation:** 2 ms / dt = 1 µs / trapezoidal.

Use this as the starting template for any non-isolated step-down
study. Drag `Vout` into the scope and press Run.

### Buck (closed-loop PI)

**File:** `examples/gallery/buck_pi_closed_loop.pulsim`
**Topology:** the same buck power stage with a PI compensator (`Kp =
0.6`, `Ki = 1500`) closing the loop on `V_out`. `Vref = 5 V`. The PI
output drives the PWM `DUTY_IN` pin via the `enable_duty_input` flag.
**Simulation:** 5 ms / dt = 1 µs.

The textbook closed-loop demo. Bump `Vref` mid-simulation by editing
the constant and re-running to see the PI response.

### Synchronous buck

**File:** `examples/gallery/synchronous_buck.pulsim`
**Topology:** replaces the freewheel diode with a low-side NMOS for
higher efficiency. Two complementary PWMs (180° apart) drive `Mh` /
`Ml`. 200 kHz switching, 12 V → 5 V.

> ⚠ Two PWMs at the same duty + 180° phase is not the same as proper
> dead-time generation; for production designs add a `delay_block`
> between the two PWMs, or replace the high-side PWM with a
> `state_machine` that respects dead time.

## DC-DC step-up

### Boost (open loop)

**File:** `examples/gallery/boost_open_loop.pulsim`
**Topology:** classic single-switch boost, 12 V → 24 V at 100 kHz, 50
% duty. `L1` boosts the input current when `M1` is on; `D1` blocks
during the off-period; `Cout` filters.

### Buck-boost (inverting)

**File:** `examples/gallery/buck_boost_inverting.pulsim`
**Topology:** classic inverting buck-boost, 12 V → −12 V at 200 kHz,
50 % duty. `Vout` is negative with respect to ground — note the
voltage probe orientation.

## Isolated DC-DC

### Flyback (coupled inductor)

**File:** `examples/gallery/flyback_coupled_inductor.pulsim`
**Topology:** coupled-inductor flyback, 36 V → 12 V. Primary
inductance 200 µH, secondary 50 µH, coupling `k = 0.98`. Output diode
and capacitor on the secondary side.

Showcases Pulsim's `coupled_inductor` device. Edit `coupling` (k) on
T1 to see the effect of leakage inductance on the output ripple.

### LLC resonant half-bridge

**File:** `examples/gallery/llc_resonant_half_bridge.pulsim`
**Topology:** LLC resonant half-bridge tuned around 130 kHz. `Lr =
80 µH`, `Cr = 47 nF`, `Lm = 320 µH`. Operates near series resonance
for soft-switching.

Use the **soft-switching KPI** in the Pulsim benchmark suite (`zvs_fraction`
on the high-side switch) to validate ZVS. The corresponding bench is
`benchmarks/circuits/lcc_resonant_inverter.yaml` in the Pulsim repo.

## Inverter

### Full-bridge inverter (single phase)

**File:** `examples/gallery/full_bridge_inverter.pulsim`
**Topology:** four MOSFET H-bridge with two complementary 20 kHz PWMs
(diagonal pairs `M1+M4` and `M2+M3`). 200 V DC bus, 10 Ω resistive
load.
**Use:** sine-wave inverter studies, dead-time experiments,
common-mode voltage analysis.

### Half-bridge with LC filter

**File:** `examples/gallery/half_bridge_lc.pulsim`
**Topology:** half-bridge with an LC output filter (220 µH + 47 µF).
50 kHz switching, 100 V DC bus.
**Use:** filter-design study, output ripple measurement,
small-signal-model validation against the analytical Bode in Pulsim's
FRA layer.

## Rectifier

### Diode bridge rectifier (full wave)

**File:** `examples/gallery/diode_bridge_rectifier.pulsim`
**Topology:** four-diode bridge rectifying a 60 Hz, 170 V peak sine
into a 1 mF / 100 Ω load. Classic line-frequency AC-DC.
**Simulation:** 100 ms / dt = 50 µs.

### Three-phase 6-pulse rectifier

**File:** `examples/gallery/three_phase_diode_rectifier.pulsim`
**Topology:** 3-phase balanced source (311 V peak, 60 Hz, 120° apart)
feeding 6 diodes (three top + three bottom), 470 µF DC bus, 50 Ω
load. The textbook 6-pulse industrial rectifier.

## Multilevel

### 3-level NPC inverter leg

**File:** `examples/gallery/npc_three_level_leg.pulsim`
**Topology:** neutral-point-clamped 3-level half-bridge — four
MOSFETs (M1-M4) + two clamp diodes (Dn1, Dn2) + split DC bus (two
200 V sources). Output through an LC filter (1 mH + 50 Ω). 5 kHz
switching.

The bench equivalent is `npc_three_level_halfbridge.yaml` in the
Pulsim benchmark suite — a textbook industrial inverter topology.

## Three-phase / vector control

### PLL grid sync (60 Hz)

**File:** `examples/gallery/pll_grid_sync.pulsim`
**Topology:** single 100 V / 60 Hz sine source feeding a `pll` block.
Outputs θ, ω, lock-error as channels into the scope.
**Settings:** `Kp = 200`, `Ki = 2000`, `f_nom = 60 Hz`.
**Simulation:** 200 ms / dt = 50 µs.

Watch θ ramp from 0 → 2π every 16.67 ms after locking, and the lock
error decay to zero. The shortest demo of the Phase 28 PLL block.

### Vector control (open loop)

**File:** `examples/gallery/vector_control_open_loop.pulsim`
**Topology:** the full Phase 28 chain — 3-phase 60 Hz sources →
**Clarke** (abc → αβγ) → **PLL** on phase A → **Park** (αβ → dq with
θ from PLL) → **InvPark** (dq → αβ) → **SVM** (αβ → 3 half-bridge
duties).

All inter-block wiring is done through metadata channels
(`alpha_from_channel: CLK.alpha`, `theta_from_channel: PLL.theta`,
etc.), not electrical wires — see the parameter sidebar on each block
to inspect the chain.

Use this as the starting template for any vector-controlled inverter
or motor-drive study. Replace the identity (Park → InvPark)
passthrough with a current-control loop to build a real FOC drive.

## Motor drive

### DC brush motor with PWM drive

**File:** `examples/gallery/dc_motor_pwm.pulsim`
**Topology:** R-L electrical model of a DC brush motor (1 Ω + 5 mH +
10 V back-EMF) driven by a 20 kHz PWM voltage source at 60 % duty.
Current probe on the armature.

**Simulation:** 10 ms / dt = 2 µs. Watch the armature current ripple
on the scope.

For a closed-loop torque-control study, add a PI controller on `Ia`
and route its output to the PWM `DUTY_IN`. Pattern: same as
`buck_pi_closed_loop`.

## Contributing a new example

1. Add a `build_<topology>` function in
   `scripts/generate_examples.py` (use existing builders as templates).
2. Add it to the `TOPOLOGIES` list at the bottom.
3. Run `python3 scripts/generate_examples.py` from the repo root.
4. Add a section to this file.
5. Verify it opens cleanly:
   `PYTHONPATH=src QT_QPA_PLATFORM=offscreen python3 -c "from
   pulsimgui.models.project import Project; Project.load('examples/gallery/<file>.pulsim')"`.
